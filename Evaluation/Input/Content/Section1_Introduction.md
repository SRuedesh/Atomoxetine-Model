Atomoxetine is a norepinephrine reuptake inhibitor and a clinically relevant CYP2D6 substrate. The source publication developed PBPK models for paroxetine, atomoxetine, and risperidone to describe CYP2D6 activity score-dependent drug-gene interactions ([Rüdesheim 2022](#5-references)).

The activity score framework was used to describe CYP2D6 activity on a finer scale than broad phenotype classes. In the source study, CYP2D6 activity score-dependent metabolism was implemented by adjusting CYP2D6 catalytic rate constants based on activity scores derived from previously published CYP2D6 substrate models.

This report evaluates the Atomoxetine PBPK model for oral Atomoxetine plasma concentration-time profiles across CYP2D6 activity-score and phenotype groups represented in the clinical study data. The model is intended to support simulation of CYP2D6-mediated drug-gene effects on Atomoxetine exposure.
